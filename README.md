# Calculator

A basic calculator application for The Odin Project, it allows for users to calculate basic mathematic operations. Built with HTML, Flexbox and JavaScript.

## Live Demo

https://nat0134.github.io/Calculator/

## About The Project

This project demonstrates basic front-end web developement skiils using fundamental Hypertext Markup Language, Cascading style sheet and Flexbox layout module. Each button is created in a table structure and styled based on their 
class. The JavaScipt component processes user input and evaluates mathematical expressions to produce calculated results.

It presents an understanding and use of:
- Semantic HTML structure
- CSS rule application for styling and layout
- The CSS cascade and specificity for precise UI styling behavior
- JavaScript event-driven programming for user interaction handling
- Designing and building expression parsing and evaluation logic for mathematical input processing

## Key Learnings

- Building an interactive calculator application using JavaScript
- Applied regex expressions to tokenize mathematical expression
- Adapting Shunting-Yard algorithm to parse and evaluate infix expressions
- Handling operator precedence, associativity and unary operations in expression passing

## Features

- Basic arithmetic operations: +, -, *, /, ^
- Support for unary operations: negation, square root, percentage
- Parenthesis handling for nested expressions
- Evaluation using operator precedence rules
- Real-time input display updates
- Keyboard support

## Limitations

- Expression editing is string-based rather than token-based
- No support for variables or memory storage
- No support for double negate function

## Known Bug

- Keyboard support inducing persistent 'sqrt' on stack

## Future Improvements

- Refactor expression handling to full token based system
- Improve unary operator handling and edge-case stability
- Implement double negate function
